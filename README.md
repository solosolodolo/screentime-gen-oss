#screentime-gen-oss
**Screentime** **GenOSS** is a free and open-source web application that helps you with your iPhone screen time limits.   
Apple has made it really easy to bypass screen time limits unless someone else has your screen time password. It’s so easy to just hit “ignore limit for today” or “remind me in 15 minutes”, even if you’ve set up a passcode that locks the settings. You could have someone else set a passcode for you, but if you need to change your screen time settings for a legitimate reason, you’ll have to contact that person unnecessarily.  
Screentime GenOSS makes it so that you can set up a screen time password in a way that you don’t remember it. All you have to do is press the button that the instructions tell you, and you will have a unique 4-digit passcode that only the software knows. Each set of instructions will be different, but they will always finish with the same passcode.
**Decoder**
To make it so that you can recover the passcode, Screentime GenOSS will compile a .txt file that contains a decoder key. If you need to change your settings, just paste the text of the .txt file into the program and it will run the program with your original passcode instead of a randomly generated one.  
**DO NOT DELETE THE .txt FILE**. You will have to do a forgot your password on your iPhone and generate a new one in the application later.
